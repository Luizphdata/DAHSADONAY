    Create `.github/workflows/ci.yml` with exactly this content:
    ```yaml
    name: CI
    on: [push, pull_request]
    jobs:
      verify:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v7
          - uses: actions/setup-node@v7
            with:
              node-version: '24'
              cache: 'npm'
          - run: npm ci
          - run: npm run build
          - run: npm run lint
          - run: npm test
    ```
    Before finalizing, spot-check that `actions/checkout@v7` and `actions/setup-node@v7` are still the current major versions (01-RESEARCH.md flags this as its one MEDIUM-confidence literal, WebSearch-sourced rather than fetched from the live Marketplace page). If a newer major is confirmed available, use it instead and note the change in the plan's SUMMARY — do not block on this check if verification is inconclusive; the pinned v7/v7 values are a safe default either way.
    Do not add a `workflow_dispatch` trigger, matrix build, or caching beyond `cache: 'npm'` — keep this minimal and literal to QUAL-04's wording (push/PR triggers `tsc -b`, lint, tests; nothing more is asked for in this phase).

|-----------|----------|-----------|-------------|------------------|
